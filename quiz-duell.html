Live-Modus einrichten

Einmalig, danach nie wieder. Für das gleichzeitige Spielen braucht es eine kostenlose Datenbank, die die Fragen zwischen euren Geräten synchronisiert.

  1. Auf console.firebase.google.com mit Google-Konto anmelden.
  2. Projekt erstellen → Name z.B. quiz → Google Analytics kannst du überspringen.
  3. Links im Menü Build → Realtime Database → Datenbank erstellen → Standort europe-west1 → Im Testmodus starten.
  4. Zahnrad oben links → Projekteinstellungen → runterscrollen zu Meine Apps → Web-Symbol </> → Name eingeben → App registrieren.
  5. Den angezeigten Block const firebaseConfig = { … } komplett kopieren und hier einfügen:
Lösung: Firebase-Konsole öffnen → links Realtime Database → oben Reiter Regeln (englisch: Rules) → den kompletten Inhalt durch das hier ersetzen → Veröffentlichen. Danach hier auf „Erneut versuchen“.
